# **第一部分：Linux Shell 脚本编程基础**

[toc]

## **1. Shell 环境与基础符号**

### **1.1. Shell 脚本执行方式**

在 Linux 中，执行 Shell 脚本主要有两种方式，它们的区别在于脚本是在一个新的子进程中运行，还是在当前的 Shell 环境中运行，这会直接影响到变量和环境的继承关系。

- **`sh/bash script.sh`**: 在一个新的子 Shell (subshell) 中执行脚本。
  - **工作方式**：系统会创建一个全新的 Shell 进程来执行脚本中的命令。
  - **特点**：子 Shell 会继承父 Shell 的环境变量，但在子 Shell 中对变量的任何修改（包括定义新变量）都不会影响到父 Shell。脚本执行完毕后，子 Shell 销毁，所有变更随之消失。
  - **适用场景**：这是最安全、最常用的执行方式，因为它能保证脚本的运行环境是隔离的，不会意外修改当前的终端环境。
- **`source script.sh` (或 `. script.sh`)**: 在当前的 Shell 环境中执行脚本。
  - **工作方式**：脚本中的命令会逐行在当前的 Shell 进程中执行，就像你直接在终端里输入这些命令一样。
  - **特点**：脚本中定义或修改的变量、函数等会直接保留在当前的 Shell 环境中。
  - **适用场景**：通常用于加载配置文件（如 `source ~/.bashrc` 使配置生效）或包含函数库的脚本，以便在当前终端中直接使用这些函数。

### **1.2. 核心特殊符号**

- **命令与逻辑控制**:

  - `|` (管道符): 将前一个命令的标准输出（stdout）传递给后一个命令作为标准输入（stdin）。这是组合命令的利器。

    ```
    # 实战案例：查看当前目录文件列表，并通过管道统计文件数量
    ls -l | wc -l
    ```

  - `&&` (逻辑与): `command1 && command2`，只有当 `command1` 成功执行（退出状态码为 0）后，`command2` 才会执行。

    ```
    # 实战案例：如果目录创建成功，则立刻进入该目录
    mkdir new_dir && cd new_dir
    ```

  - `||` (逻辑或): `command1 || command2`，只有当 `command1` 执行失败（退出状态码非 0）后，`command2` 才会执行。

    ```
    # 实战案例：如果 ping 不通某个地址，则打印错误信息
    ping -c1 www.a-non-existent-site.com || echo "错误：无法连接到服务器"
    ```

- **变量与注释**:

  - `$` (变量引用): 用于获取变量的值。
  - `#` (注释): 用于解释代码，`#` 之后到行尾的内容都会被 Shell 忽略。

- **引号**:

  - `''` (单引号/强引用): 内部所有字符都视为普通字符，不进行任何变量解析或命令替换。

  - `""` (双引号/弱引用): 内部会进行变量解析 (`$VAR`) 和命令替换。

  - \``` (反引号/命令替换): `     ` `command` ` ` 等同于 `(command)\`，会执行其中的命令并将其标准输出结果替换到当前位置。推荐使用 \`(...)` 形式，因为它更清晰且可以嵌套。

    ```
    # 实战案例：演示不同引号的区别
    USER_NAME="Alex"
    echo '你好, $USER_NAME'   # 输出: 你好, $USER_NAME
    echo "你好, $USER_NAME"   # 输出: 你好, Alex
    
    # 实战案例：使用命令替换获取当前日期
    CURRENT_DATE=$(date +%F)
    echo "今天是: $CURRENT_DATE"
    ```

### **1.3. 输入/输出重定向**

- `>`: 标准输出重定向（覆盖）。如果文件不存在则创建，如果存在则清空文件内容再写入。

- `>>`: 标准输出重定向（追加）。将内容追加到文件末尾。

- `<`: 标准输入重定向。将文件的内容作为命令的输入。

- `2>`: 错误输出重定向。专门用来重定向命令执行时产生的错误信息。

- `&>`: 将标准输出和错误输出同时重定向。

  ```
  # 实战案例：
  # 将当前目录列表覆盖写入到 file.txt
  ls -l > file.txt
  
  # 将一行文本追加到 file.txt 末尾
  echo "这是新的一行" >> file.txt
  
  # 统计 file.txt 的行数
  wc -l < file.txt
  
  # 尝试访问一个不存在的文件，将错误信息写入 error.log
  cat non_existent_file 2> error.log
  ```

### **1.4. 文件与路径通配符**

通配符用于匹配文件名，简化文件操作。

- `*`: 匹配任意长度的任意字符。

- `?`: 匹配任意单个字符。

- `[]`: 匹配方括号中指定的任意一个字符。如 `[abc]` 匹配 a 或 b 或 c。可以使用范围，如 `[a-z]`。

- `[^]`: 匹配不在方括号中指定的任意一个字符。

- `{}`: 生成序列。

  ```
  # 实战案例：
  # 删除所有以 .log 结尾的文件
  rm -f *.log
  
  # 查找名为 file 后跟一个任意字符的文件，如 file1, fileA
  ls file?
  
  # 复制所有以 a, b, c 开头的文件到 /tmp 目录
  cp [abc]* /tmp
  
  # 快速创建三个目录
  mkdir {data,backup,logs}
  ```

## **2. Shell 脚本核心语法**

### **2.1. 变量**

- **定义**: `VAR_NAME="value"` (注意：等号两边不能有空格)。

- **引用**: `$VAR_NAME` 或 `${VAR_NAME}` (在复杂字符串拼接中，使用花括号可以明确变量边界，避免歧义)。

- **特殊变量实战**:

  ```
  #!/bin/bash
  # 脚本名: test.sh
  # 执行方式: ./test.sh param1 param2
  
  echo "脚本自身的名称是: $0"
  echo "第一个参数是: $1"
  echo "第二个参数是: $2"
  echo "总共有 $# 个参数"
  echo "所有参数作为一个字符串: $*"
  echo "所有参数作为独立的字符串: $@"
  
  # 检查上一个命令是否成功
  ls /root > /dev/null
  if [ $? -eq 0 ]; then
      echo "ls /root 命令执行成功"
  else
      echo "ls /root 命令执行失败"
  fi
  ```

### **2.2. 函数**

函数可以将一系列命令打包，方便复用。

- **定义与调用实战**:

  ```
  #!/bin/bash
  
  # 定义一个函数，用于打印问候语
  greet() {
      local name=$1 # 使用 local 关键字定义的变量只在函数内部有效
      echo "你好, $name! 欢迎学习 Shell。"
  }
  
  # 调用函数并传递参数
  greet "小明"
  greet "小红"
  ```

### **2.3. 流程控制：条件语句**

- **`if` 语句与 `test` 命令**: `if` 语句的条件判断通常由 `test` 命令或其等效形式 `[` `]` 和 `[[` `]]` 提供。

  - **`[` `]` (test)**: POSIX 标准，兼容性好。
  - **`[[` `]]`**: Bash 扩展功能，更强大和安全。
    - **区别与推荐**: `[[` `]]` 能防止变量为空时产生的逻辑错误，并支持 `&&`, `||`, `>` 等更自然的逻辑操作符，**推荐在 Bash 脚本中使用 `[[` `]]`**。

  ```
  # 实战案例：对比 [ ] 和 [[ ]]
  VAR=""
  # [ -n $VAR ] # 这会因为 $VAR 为空而报错
  if [[ -n "$VAR" ]]; then echo "变量不为空"; else echo "变量为空"; fi # 正确处理
  
  # 实战案例：检查端口是否被占用
  PORT=80
  if netstat -lntp | grep -q ":${PORT}\b"; then
      echo "端口 $PORT 正在被监听。"
  else
      echo "端口 $PORT 空闲。"
  fi
  ```

- **`case` 语句**: 适用于多分支选择。

  ```
  #!/bin/bash
  # $1 是脚本的第一个参数
  case "$1" in
      "start")
          echo "正在启动服务..."
          ;;
      "stop")
          echo "正在停止服务..."
          ;;
      "restart")
          echo "正在重启服务..."
          ;;
      *)
          echo "用法: $0 {start|stop|restart}"
          exit 1
          ;;
  esac
  ```

### **2.4. 流程控制：循环语句**

- **`for` 循环**:

  ```
  # 实战案例：打印九九乘法表 (使用 expr)
  # expr 是一个较早的数学运算命令，\* 需要转义
  for i in {1..9}; do
      for j in $(seq 1 $i); do
          echo -n "$j*$i=$(expr $j \* $i)\t"
      done
      echo
  done
  ```

- **`while` 循环**:

  ```
  # 实战案例：逐行读取文件并处理
  while read -r username; do
      if [ -n "$username" ]; then # 确保行不为空
          mkdir -p "/home/$username"
          echo "为用户 $username 创建了目录"
      fi
  done < "user.txt"
  ```

### **2.5. 循环控制命令**

- `break [n]`: 跳出循环。`n` 表示跳出 `n` 层循环，默认为 1。

- `continue [n]`: 跳过本次循环。`n` 表示跳到第 `n` 层循环的下一次迭代。

  ```
  # 实战案例：使用 continue 2 跳出内层循环
  for i in {1..3}; do
      echo "外层循环: #$i"
      for j in {A..C}; do
          if [ $i -eq 2 ] && [ $j == "B" ]; then
              echo "  (跳过外层循环的剩余部分)"
              continue 2 # 当 i=2, j=B 时，直接开始 i=3 的循环
          fi
          echo "  内层循环: $j"
      done
  done
  ```

### **2.6. 脚本美化：终端颜色控制**

可以使用 ANSI 转义序列来为脚本输出添加颜色，增强可读性。

```
#!/bin/bash
# 定义颜色变量
RED="\e[1;31m"
GREEN="\e[1;32m"
YELLOW="\e[1;33m"
ENDCOLOR="\e[0m"

echo -e "${GREEN}成功:${ENDCOLOR} 操作已成功完成。"
echo -e "${YELLOW}警告:${ENDCOLOR} 磁盘空间即将用尽。"
echo -e "${RED}错误:${ENDCOLOR} 无法连接到数据库。"
```

# **第二部分：Linux 文本处理核心工具**

## **3. 正则表达式 (Regular Expressions)**

### **3.1. 简介与区别**

正则表达式是一种用于描述、匹配一系列字符串模式的强大工具。它与**通配符**的核心区别在于：

- **作用对象**: 正则表达式处理**文件内容**；通配符处理**文件名**。
- **语法规则**: 许多符号（如 `*`）在两者中的含义完全不同。

### **3.2. 基础正则表达式 (BRE)**

| 符号  | 描述                           |
| ----- | ------------------------------ |
| `^`   | 匹配一行的开头                 |
| `$`   | 匹配一行的结尾                 |
| `.`   | 匹配任意一个单个字符           |
| `*`   | 匹配前一个字符出现 0 次或多次  |
| `[]`  | 匹配中括号内的任意一个字符     |
| `[^]` | 匹配不在中括号内的任意一个字符 |

### **3.3. 扩展正则表达式 (ERE)**

| 符号    | 描述                           |
| ------- | ------------------------------ |
| `+`     | 匹配前一个字符出现 1 次或多次  |
| `?`     | 匹配前一个字符出现 0 次或 1 次 |
| `|`     | 或，匹配多个表达式之一         |
| `()`    | 将多个字符捆绑成一个组         |
| `{n,m}` | 匹配前一个字符重复 n 到 m 次   |

### **3.4. Perl 兼容正则表达式 (PCRE) 与零宽断言 (进阶)**

标准的 `grep` 和 `sed` 不支持零宽断言，但 GNU `grep` 可以通过 `-P` 参数来启用 PCRE 引擎。零宽断言只匹配一个**位置**，而不是具体的字符，它本身不占任何宽度。

- **`(?=...)` - 正向先行断言**: 要求当前位置**后面**的字符串必须匹配 `...`。

  ```
  # 实战案例: 提取后面跟着 "省" 的城市名 (不包含"省")
  echo "广东省 湖南省 北京市" | grep -oP '\w+(?=省)'
  # 输出: 广东 湖南
  ```

- **`(?<=...)` - 正向后行断言**: 要求当前位置**前面**的字符串必须匹配 `...`。

  ```
  # 实战案例: 提取价格数字 (前面必须是 "价格:")
  echo "商品ID:123 价格:99.8元" | grep -oP '(?<=价格:)[0-9.]+'
  # 输出: 99.8
  ```

## **4. 文本三剑客**

### **4.1. `grep`：文本过滤与搜索**

- **作用**: 在文件中根据指定的模式搜索并显示匹配的行。
- **常用参数**: `-i` (忽略大小写), `-v` (反向匹配), `-n` (显示行号), `-o` (只显示匹配内容), `-E` (扩展正则), `-P` (Perl正则), `-c` (统计行数)。

### **4.2. `sed`：流编辑器**

- **作用**: 对文本进行非交互式的编辑，擅长**行**的增、删、改、查和内容**替换**。
- **常用命令**: `p` (打印), `d` (删除), `s` (替换), `i` (插入), `a` (追加)。

### **4.3. `awk`：报表生成器**

- **作用**: 强大的文本分析工具，擅长将文本按**列**（字段）进行分割处理。

- **工作原理**: `BEGIN` -> 逐行处理 `模式 {动作}` -> `END`

- **常用内置变量**:

| 变量 | 描述 |
| :--- | :--- |
| `NR` | 当前处理的行号 |
| `NF` | 当前行的字段（列）数 |
| `$0` | 当前整行的内容 |
| `$1`, `$2`... | 第 1、2...列的内容 |
| `FS` | 输入字段分隔符 (可用 `-F` 指定) |
| `OFS` | **输出**字段分隔符，默认为空格 |
| `RS` | **输入**记录（行）分隔符，默认为换行符 |
| `ORS` | **输出**记录（行）分隔符，默认为换行符 |

  ```
  # 实战案例: 使用 OFS 重新格式化输出
  # 将 /etc/passwd 的用户名和 Shell 之间用 " --- " 分隔
  awk -F: -v OFS=" --- " '{print $1, $7}' /etc/passwd | head -n 3
  ```

- **数组与循环**:

  ```
  # 实战案例: 统计 Nginx 访问日志中每个 IP 的访问次数
  awk '{ip_counts[$1]++} END {for (ip in ip_counts) print ip_counts[ip], ip}' access.log | sort -rn
  ```

# **第三部分：系统管理与脚本实践**

## **5. Linux 系统权限管理**

### **5.1. 文件与目录权限详解**

| 权限         | 对文件的作用         | 对目录的作用                   |
| ------------ | -------------------- | ------------------------------ |
| **r (读)**   | 读取文件内容 (`cat`) | 列出目录下的文件名 (`ls`)      |
| **w (写)**   | 修改文件内容         | 在目录中创建、删除、重命名文件 |
| **x (执行)** | 作为命令执行         | 进入 (`cd`) 该目录             |

### **5.2. 默认权限与 `umask`**

- `umask` 定义了新建文件或目录时需要**减去**的权限。
- **文件最终权限**: `666 - umask`
- **目录最终权限**: `777 - umask`

### **5.3. 用户提权 `sudo`**

- **作用**: 允许普通用户以 root 身份执行授权的命令。
- **配置**: 使用 `visudo` 命令安全地编辑 `/etc/sudoers` 文件。
- **示例**: `dev ALL=(ALL) /usr/bin/systemctl restart httpd`

# **第四部分：附录**

## **7.1. 异或运算 (Bitwise XOR)**

异或是一种二进制逻辑运算，用 `^` 表示。

- **规则**: 两个操作数相同为 `0`，相异为 `1`。
- **示例**: `5 ^ 3`
  - `5` 的二进制是 `0101`
  - `3` 的二进制是 `0011`
  - `0101 ^ 0011` = `0110` (二进制) = `6` (十进制)

## **7.3. 常用辅助命令**

### 系统与进程管理 (System & Process Management)

| 命令                        | 描述与示例                                                   |
| --------------------------- | ------------------------------------------------------------ |
| `systemctl restart network` | **重启网络服务**：在大多数现代 Linux 发行版（如 CentOS 7+）中，用于应用网络配置更改。 |
| `pkill [process_name]`      | **按名称杀死进程**：比 `kill` 更方便，可以直接通过进程名结束一个或多个进程。例如，`pkill nginx` 会杀死所有名为 nginx 的进程。 |
| `lastlog`                   | **显示用户最近登录信息**：查看服务器上所有用户最后一次登录的时间、来源等信息，便于安全审计。 |

### 网络工具 (Network Tools)

| 命令                           | 描述与示例                                                   |
| ------------------------------ | ------------------------------------------------------------ |
| `ssh [user]@[host]`            | **远程连接**：安全地连接到远程 Linux 服务器。                |
| `netstat -lntup` / `ss -lntup` | **查看网络端口**：列出所有正在监听的 TCP (`t`) 和 UDP (`u`) 端口，并显示端口号 (`n`) 和对应的进程信息 (`p`)。`ss` 命令在处理大量连接时效率更高。 |
| `lsof -i:[port]`               | **查看端口占用**：精确地找出是哪个进程占用了指定的端口。例如，`lsof -i:80` 会显示占用 80 端口的进程。 |
| `nmap -p[port] [ip/domain]`    | **端口扫描**：探测远程主机的端口是否开放。例如，`nmap -p22,80 192.168.1.1` 会检查目标主机的 22 和 80 端口。 |

### 软件包管理 (Package Management - YUM/DNF)

| 命令                                                     | 描述与示例                                                   |
| -------------------------------------------------------- | ------------------------------------------------------------ |
| `yum install [packages...] -y`                           | **批量安装基础包**：常用于新服务器的初始化，一次性安装所有必要的开发和运维工具。 |
| `yum install --downloadonly [pkg] --downloaddir=[/path]` | **只下载不安装**：在无法连接外网的环境中非常有用。可以先在一台能上网的机器上下载好 RPM 包，然后拷贝到目标服务器上进行离线安装。 |

### 文件与磁盘 (File & Disk)

| 命令                          | 描述与示例                                                   |
| ----------------------------- | ------------------------------------------------------------ |
| `head [file]` / `tail [file]` | **查看文件头尾**：快速预览大文件的开头或结尾部分，`tail -f` 还可以实时监控文件的新增内容。 |
| `find -inum [inode] -delete`  | **通过 inode 删除文件**：当遇到文件名包含无法输入的特殊字符时，可以先用 `ls -i` 找到文件的 inode 号，然后用此命令将其安全删除。 |

### Docker 相关

| 命令                                   | 描述与示例                                                   |
| -------------------------------------- | ------------------------------------------------------------ |
| `docker rm -f [container]`             | **强制删除容器**：当容器无法正常停止时，可以使用 `-f` 参数强制删除一个正在运行的容器。 |
| `docker save [image] | gzip > .tar.gz` | **导出并压缩镜像**：将一个 Docker 镜像打包成一个压缩文件，方便在不同主机之间迁移或备份。 |
