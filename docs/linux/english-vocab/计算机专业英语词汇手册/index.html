基础操作词汇​

1.1 基础命令​

英文中文示例
enable开启/启动enable service
disable关闭/禁用disable port
configure/config配置config network
continue继续continue installation
quit退出quit application
set设置set parameter=value
apply应用apply changes
cancel取消cancel operation

1.2 系统状态​

+----------------+----------------+
|    Active      |    Inactive    |
| (激活/运行中)  | (未激活/已停止) |
+----------------+----------------+
|      ON        |       OFF      |
+----------------+----------------+
|      Dead      |    Error       |
| (死亡/失效)    | (错误状态)     |
+----------------+----------------+

系统配置术语​

2.1 安装与登录​

  • Begin install - 开始安装
  • login - 登录系统
  • system - 系统核心
  • control - 控制面板/管理

2.2 连接管理​

  • edit a connection - 编辑连接（如网卡配置）
  • Connection established - 远程连接已建立
  • dead - 连接死亡/失效
[用户] ----(登录)----> [系统] ----(配置)----> [网络]
       <----(连接建立)----       <----(激活)----

网络与通信​

3.1 网络基础​

英文中文说明
network网络计算机互联系统
connection连接网络链路
static静态固定配置
dynamic动态自动获取
protocol协议通信规则

3.2 网络设备​

  • router - 路由器
  • switch - 交换机
  • hub - 集线器
  • modem - 调制解调器
  • firewall - 防火墙

3.3 网络命令​

ping 8.8.8.8          # 测试网络连通性
ifconfig              # 查看网络接口
netstat -an          # 查看网络连接状态
traceroute example.com # 路由跟踪

文件系统操作​

4.1 文件操作​

英文中文示例
file文件file.txt
directory目录/home/user
create创建create file
delete删除delete file
copy复制copy file
move移动move file
rename重命名rename file

4.2 文件属性​

  • read - 读取权限
  • write - 写入权限
  • execute - 执行权限
  • hidden - 隐藏属性
  • system - 系统属性

4.3 常见文件错误​

错误提示含义解决方案
No such file or directory文件/目录不存在检查路径是否正确
File exists文件已存在使用不同名称或覆盖
Permission denied权限不足使用sudo或修改权限
the same file重复文件名重命名文件

编程与开发​

5.1 编程基础​

英文中文说明
program程序计算机指令集合
command命令执行操作的指令
variable变量存储数据的容器
constant常量固定不变的值
function函数执行特定任务的代码块

5.2 数据类型​

  • integer - 整数
  • float - 浮点数
  • string - 字符串
  • boolean - 布尔值
  • array - 数组
  • object - 对象

5.3 控制结构​

if condition:           # 条件判断
    do_something()
elif other_condition:
    do_other()
else:
    do_default()

for item in iterable:  # 循环
    process(item)

while condition:       # 循环
    do_something()

错误与异常处理​

7.1 常见错误类型​

英文中文说明
error错误程序问题
fail失败操作未成功
exception异常运行时错误
warning警告潜在问题
crash崩溃程序终止

7.2 系统错误​

错误提示含义解决方案
command not found命令找不到检查命令拼写或安装
Permission denied权限拒绝检查用户权限
Device not found设备未找到检查设备连接
Out of memory内存不足关闭其他程序

7.7.3 错误处理方法​

# 检查命令执行状态
if command; then
    echo "Success"
else
    echo "Failed with error $?"
fi

捕获异常
try {
    risky_operation()
} catch (Exception e) {
    handle_error(e)
}
