# 美学研究范畴

美学的规定性：

美学的学科特点：

1. 美学是对审美现象的一种反思（先有一个现象 将现象抽离出来 追问现象背后本质的问题）
2. 对审美规律的探寻（规律背后的规律不是规律本身） 美学不是学以致用的是学以致智的
3. 对审美文化的分析（审美思潮 审美形态 对社会背景和文化背景）

事物设计的特别具象就会让人联想到使用功能，不会显现出它的无功利性。

审美是一种权利 一种趣味的隔离 一种权力的结构（少数人能看懂的往往是被认为是美的 能被人一望而知的往往都是不美的 带有阶级性意味）

质疑：我们评价一个事物美或者不美的时候是站在什么立场或角度看待的？为什么我们所认为的美要比另一种高级？ 审美是否存在鄙视链）

审美的背后可能是一种权利 可能是一种文化资本在支撑 可能是特定的社会北京 特定的阶级铸造了特定的审美趣味 背后可能有特别复杂的权利结构在支撑 但主体本身无感知

科学划分

审美关系的四个维度

人与自身  心理学美学 （格式塔美学 人体美学）

格式塔审美心理理论认为，审美知觉不是对审美对象元素的机械复写，而是对有意义的整体结构的把握。整体不能从各部分相加的和中求得，各部分要素的意义取决于它在整体中的位置与作用。审美知觉对审美对象，有一种追求统一秩序和完整形态的倾向，是对美的形象的创造性把握，而不是对感性材科的机械复制。艺术家的视觉组织和整个心灵，都不是某种种机械地复制现实的装置；他的艺术活动不是对客观事物偶然性表象所进行的照相式录制，而是对有意义的现实整体体结构式样的把握。总之，不把握事物的整体或统一结构，就不能创造和欣赏艺术。对于审美心理研究来说，[格式塔心理学](https://baike.baidu.com/item/%E6%A0%BC%E5%BC%8F%E5%A1%94%E5%BF%83%E7%90%86%E5%AD%A6/1331198)的许多理论，如“同型论”、“简化原则”、“似动现象”理论等，都有相当的应用价值，被引入[审美心理学](https://baike.baidu.com/item/%E5%AE%A1%E7%BE%8E%E5%BF%83%E7%90%86%E5%AD%A6/1388450)研究领域后，取得了相当多的成果。它对审美知觉的特点和规律的研究富有启发意义，但是把审美感知和事物的完整形式，仅仅看成是人的先天神经系统的组织机能，排除了生活经验和理性知识的作用，从总体上看来，具有唯心主义倾向。
