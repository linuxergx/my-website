02 全身训练

平板杠铃卧推 —>胸肌 平板杠铃卧推​

动作要求：

  1. 握距 肩宽1.5倍
  2. 手腕中立位：第二排指关节向上 位置不对伤手腕影响训练
  3. 下落位置 —>小臂垂直地面 肘不过肩 大臂平行地面或略低 大臂与躯干呈75°夹角
  4. 高度：杠铃下落于胸上2-4指 位置： 握点位于乳头链接线正上方
  5. 脚跟踩实地面 脚距略宽于肩
  6. 脚尖收到与膝盖垂直，脚尖不过膝 （脚发力感受到脚于地面的抵抗关系）
  7. 大腿前侧需要放松 肩胛向下对抗 肩胛骨不需要向后收

在做推举训练时，大臂与躯干之间的夹角应为多少度？​

在推举训练中，大臂与躯干之间的夹角应保持在75度左右，这是正确的结构要求。

在做卧推时，如何正确地踩脚和使用臀部力量？​

在做卧推时，往下踩的力不仅需要来自腿部，更关键的是要利用屁股的力量。通过让臀部收紧并使髋关节伸展，这样能有效传递下压力量。同时，脚下的劲儿是向下踩地面，并配合往上推身体的力，形成踩和推的结合。

如何保持身体空间稳定并进行卧推训练？​

在进行卧推训练时，要始终保持屁股收紧、腿打开的状态，这会让下背和动板自然驱动并保持空间能力，无需让身体完全压实地面。在整个过程中都要找寻挺胸的感觉，确保肩胛骨在凳板斜面不往里夹而是往斜下方向顶住凳子。

坐姿杠铃推肩（史密斯机）—>肩膀 史密斯推肩​

动作要求

  1. 屁股要离凳板一竖拳 肘关节不要锁死
  2. 非史密斯机需要将杠铃沿面部推举到头顶正上方。

下落底端杠铃应放置到哪？

下落底端杠铃应放置到下额前，确保小臂与地面垂直，并保持杠铃身体前后位置贴合地面。

在训练中如何确保正确的动作执行？

要记住小臂和地面垂直，这不仅是一个技术要求，更是一种意识和动作的结合。练习时需有意识地往前收大臂，保证在特定角度下全程完成训练，避免推举过程中肌肉因压力过大导致腕部受伤或胸中心疼痛。

训练中遇到推举问题时应如何处理？在推举练习中如何控制下落速度并启动推举？

在推举或外推举训练中，如果出现严重问题如TFCC损伤，应首先减轻疼痛，并尽量恢复到最佳功能状态。在推举练习中，需吸气慢速控制下落速度，同时注意有意识地大臂手指往前收，胸顶住来启动推举动作。

对于器械使用，有什么快速上手的建议吗？

建议没练过的同学快速上手器械，练习时不要锁死关节，让手臂保持伸直放松的状态即可。

高位下拉—> 背 高位下拉：三种变式​

动作要求：

  1. 握距肩宽1.5
  2. 收肘 后仰15°
  3. 下拉到上胸位置
  4. 微微拧把 立背 整个行程是弧线动作
  5. 后半手掌根位置锁把

史密斯机深蹲—>股四头 4字蹲 4字蹲​

动作要求

  1. 脚距=肩宽 一般不超过肩宽1.2倍数
  2. 杠铃中心垂直在脚背方向 即脚踝正上方，并保持脚趾实地，找背人的感觉。
  3. 髋膝联动 双绳效应下蹲
  4. 起杠在胸锁位置

在史密斯杠铃深蹲中，男女的深蹲模式是否一样？深蹲史密斯杠铃操作要求中提到的脚距和肩宽是什么意思？​

男女的深蹲模式是一样的，都涉及臀腿各一半的练习，女孩子臀腿下肢也都有练习的空间。脚距=肩宽，但实际操作时需根据受训者个人身体结构进行调整，不会超过肩宽1.2的标准。

杠铃的杠点具体是指什么位置？​

杠铃的杠点指的是杠铃和身体接触的位置，杠铃每次背杠的时候应该避开第七颈椎往下走到上前方的位置，避开颈后凸起的骨头，确保稳定后开始深蹲训练。

视线在深蹲训练中应该如何放置？​

在深蹲训练的基础模式中，视线需保持水平向前看，以维持对杠铃的稳定感觉，并且在深蹲模式不稳之前，避免低头看向地面。

在调整杠铃高度时，应该注意什么？​

在调整杠铃高度时，应确保胸锁在杠铃前部，避免过低导致背压力过大，同时保持稍微有点背人的感觉，确保在脚背垂直杠铃的情况下，重心不会往前顶，找到合适的初始高度后逐步调整至适合自己的状态。

在做深蹲类训练时，如何找到并保持正确的身体位置？​

在深蹲训练中，首先要求肩膀顶住，然后逐渐往后坐，确保眼睛往前看。接着进行下蹲启动走，要注意观察杠点和脚背是否在一条线上。调整双脚间距，同时保持挺胸抬头，关注髋部和膝盖的位置，以及脚尖收回的程度。在整个过程中，强调的是找刹车的感觉和维持肌肉的形态与维度，而不是速度。（双绳效应）

针对有膝关节结构病变风险的学员，在进行深蹲训练时需要注意什么？​

对于可能存在膝关节结构病变（如半月板重度磨损、韧带断裂等）的学员，应避免快速下蹲和剧烈运动，而是要在自己能控制循环和节奏的情况下适度练习，重点在于建立下肢维度或提高腿部分离度，不论胖瘦高矮都适用。在练习时，特别要注意全程保持骨盆稳定，以防造成额外的压力和损伤。

俯卧腿弯举—>腘绳肌群​

在进行俯卧腿弯曲训练时，如何正确调整姿势以刺激大腿后侧肌群？

在进行俯卧腿弯曲训练时，要求全程尽量保持骨盆后位，避免骨盆前倾，全程低头保持头部埋在垫子后面以保护脊柱。同时，调整脚板位置适应个人腿长，然后通过大力臂和小腿主动对抗阻力，保持小腿靠近大腿，不要试图勾脚。在训练过程中，始终想象将小腿向远伸直并拉回，配合呼吸，找到小腿对大腿的挤压感。对于男性学员，若有翘屁股的习惯，在勾脚之前应先想伸展腿部至最远，以增强腿部后压力。女性学员则保持与肩同宽的脚距，同样要求半离心控制，爆发性勾起并慢速放落，确保动作规范有效。

杠铃弯举—>二头​

动作要求

  1. 以小指方向挂杠 逐节抓握 建立后半手掌对抗
  2. 微微外旋手腕
  3. 肘窝也要朝前，肩胛沉稳，重心压在中立位置，保持大臂结构不动，小臂主动靠近大臂，并且在整个过程中手腕保持中立，建立呼吸节奏

在训练中，如何调整抓握习惯以优化二头肌的形态和功能？​

首先，你需要改变抓握杠铃的方式。每次训练时，确保手指从远端开始挂住杠铃，并用最远端的手指头逐节去转动和扣住杠铃。在整个过程中，小指、无名指和中指应保持完整的尺度，用它们来帮助建立对抗力。通过这样的抓握方式，可以确保二头肌以一个外旋位的状态工作，从而实现最大化收缩。

在杠铃训练中，身体结构的稳定性对于成功完成动作的重要性是什么？​

在进行杠铃训练时，无论负重多大，身体结构的稳定性至关重要。如果在做动作时感觉形态不稳定，比如手臂僵直或身体摇晃，这说明你的结构是松散的，处于纯惯性状态。正确的身体结构应该是结构稳定，如在杠铃二头肌训练中，即使手握杠铃，肘窝也要朝前，肩胛沉稳，重心压在中立位置，保持大臂结构不动，小臂主动靠近大臂，并且在整个过程中手腕保持中立，呼吸顺畅。只有这样，才能确保动作的有效性和安全性。

在杠铃训练中，小指方向的握力如何影响整体效果？​

在整个杠铃训练过程中，小指方向的握力是连续且重要的。你需要有意识地保持小指方向的握力不断，这样能够建立起后半手掌对抗的结构。这种习惯不仅适用于杠铃训练，对于未来所有类似杠铃的固定把列训练都至关重要。只有这样，才能保证动作的正确性和肌肉力量的有效发挥。

仰卧杠铃臂屈伸—>三头​

  1. 大臂初始位置要求与地面垂直。
  2. 手腕关节在下落过程中应保持中立位，即二排指节朝上微收，手肘向脚的方向。

上肢横向宽度较大的会员，握距可以适当放宽至与肩同宽；而对于上肢较窄的会员，握距采用略窄于肩即可。

在进行仰卧杠铃练习时，如何确保安全有效的动作执行？​

要确保大臂全程不动，手臂自然伸直，在吸气后下落杠铃至额头上方2到4指的高度，并在呼气前上伸直时保持手臂自然伸直，肘部不要过度向前平开或往里收，同时注意控制杠铃的速度，避免快速下落造成耸肩、松肘的情况。

在教学过程中，教练员应采用余光观察并及时给予指导，确保会员的动作正确且安全。

臀桥—> 臀​

  1. 训练臀峰
  3. 坐在凳板这边，用坐骨作为参照点，腿自然伸直，脚跟点地，
  4. 身体垂直下落，用屁股去找地面，确保肩胛骨中上背全部顶住，杠铃应放置在地上，且单杠（杠铃片）足够让练习者的腿伸过去，屁股应保持垂直滑下。
  5. 启动过程中，保持上背垂直往上顶起，小腿与地面垂直，小腿与大腿在90度角时保持稳定，不同性别在达到顶峰时有不同要求，男性需要停顿并夹紧臀部2-3S，女性则直接控制向后运动。
  6. 下落阶段，不论男女，不需要全程卡住杠铃，只需缓慢寻找地面，让臀部充分拉长，找到一个感觉阻力的位置停止下落，下落过程中的脚部力要往上登，避免滑动。
  7. 男下落2/3 行程

动作要点 技术片的作用和特点是什么？ 技术片是一种直径高度固定的杠铃片，方便练习者提高起量能力、稳定技术和结构，并且重量不同，但包胶片重量会变化，不适合练习起量能力。

在训练时，如何确保单位时间内训练容量不降低，并且保持正常水平？​

为了保证单位时间内训练容量正常且不降低，即使四个动作完成也要控制在四十分钟内。可以分上下午练习

训练的具体安排是什么样的？​

在训练时，首先从腿部开始，包括腿前腿后等动作，然后进行上肢的初级练习，如二头三头肌等。中午和晚上的训练要按照计划进行，同时强调在训练时不要浪费时间，要认真执行。

对于强度调整的空间，有什么具体要求？​

在训练中，允许在保持重量不变的情况下，有一定的次数调整区间，这个区间通常为16到20左右。比如六组某个动作时，可以在20RM和16RM之间选择，但重点是要完成六组，具体数值根据个人情况灵活调整。

**热身组数和正式训练组数是如何安排的？训练过程中重量变化和呼吸能力、体能损耗的关系是什么？​

热身部分为2到3组，正式训练部分包含六组，每组都对应一定的重量。在六组完成后，允许有一定程度的强度调整，但整体上要适应高组数、高密度的训练方式。在训练过程中，会涉及到重量变化的问题，但初期重点在于适应这种高组数、高密度的训练模式。随着训练的深入，呼吸能力和身体体能损耗会逐渐适应并提高。

针对之前有训练经历的学员，应该如何选择训练模式？​

对于有一定训练经历的学员，可以选择走终极体能的双分化训练模式，具体练习安排可以参考教练指导，确保训练频率和时间合理安排。

对于有训练经历但小基数的学员，应该如何进行增肌期训练？​

对于有训练经历的小基数学员，在增肌期可以采用胸背肩腿全面发展的模式进行训练，这个模式适合他们当前的训练需求，不用担心像大基数学员那样需要进行特定部位的练习。

对于不同级别的训练者，如何安排练习次数和组数？训练计划的具体执行要求是什么？​

初级训练者通常建议四组正式训练，每组动作根据体能水平调整次数，例如中提轻肥中起肥胖者可能做20、16、12、9个等。而高级训练者的训练量会更大，需要根据他们的体能等级来设定训练部位和动作个数。从明天开始，所有学员必须按照电子版训练计划执行训练，并强调训练时尽量地下进行。另外，训练过程中要充分利用地下一层空间资源，提升训练效果和安全性。

对于增肌群体的身体指标有哪些要求？​

对于增肌群体，男生体脂率应低于17%，女生体脂率应低于23%。

在增肌阶段，饮食是否可以随意选择？增肌阶段的饮食计算方法是什么？​

不是所有人都能随心所欲地选择食物，增肌阶段需要控制饮食，不是想吃什么就吃什么。尤其是对于外围型人群，要注意碳水化合物的种类和摄入量，以避免引发炎症等问题。增肌阶段饮食计算大致为体重公斤数乘以5，一般在5到6区间，如果训练能力很高可能达到7，但通常建议保持在5到6之间。碳水化合物摄入要精选，确保每日碳水摄入量适中。
