06 肩部训练

外形要求：饱满球状，虎头肩，南瓜肩 侧重侧面

三角肌:​

无论男女都需要练

前束：​

起于锁骨外侧半

功能：​
  1. 与单关节前平举类及双关节窄距推举类为主
  2. 肩关节水平内收 ，协同肩屈，主导肩部前中束推举类
  3. 肩关节内宣 协同肩屈，侧重前束整体厚度偏内侧

中束：​

肩峰 体态: 影响躯干段正面观，胸肩视觉宽度 功能：肩关节外展 （以单关节侧平举及双关节提拉类为主）

后束：​

起于肩胛冈 止点： 肱骨三角肌粗隆 功能： 1.肩关节伸 2. 肩关节水平外展，（以单关节飞鸟类，及双关节宽距提拉类为主，侧重提升后束整体厚度 3. 肩外旋 （协同肩关节水平外展，调整后束于肩胛骨面小肌群厚度

侧重前中训练日：​

推举类动作优先，侧平举类增强，后束弱项调整

侧重中厚训练日：​

中束段优先 后束段增强 变式推举类调整

前中推举类：​

史密斯推肩​

坐姿杠铃推肩（侧重前中束厚度） 强度区间：8-20rm 无论增肌减脂 握距：肩宽1.5以内 抓握点：小臂于地面垂直杠铃初始位置于下颌前 受限体位： 小臂不垂直地面， 肩关节外旋受限，或者肩胛骨前引 放松胸大肌 胸小肌 激活冈下肌 小圆肌。弹力带L型外旋，招财猫 激活中下斜方菱形肌， 提高肩胛下降 下回旋与后缩稳定 俯卧W下拉

坐姿哑铃推肩​

训练目的：提高稳定性 增强肌肉质量 侧重三角肌前中束厚度，提高卧推稳定性 强度： 10-20rm 稍微向前倾斜30-45度（肩胛面），这样可以更好地保护肩关节

人体正中矢状面
  |
  |
  |
  |    肩胛面（肩关节运动最佳角度）
  |    /  
  |   /   
  |  /    
  | /     
  |/      
  +-------> 冠状面（身体正侧面）

将大臂在冠状面水平向内收起一些大约30度左右

哑铃侧平举：​

训练目的： 侧重提升三角肌中束整体厚度，调整肩部整体外抛弧度。 站位调整：重心微微前移，大臂与小臂夹角100-140°，拳心相对，八字位也行。不往后顶背，保持挺胸立背，肩带动肘，肘向外画弧。切忌肘内旋。
