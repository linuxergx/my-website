05 康复 肩

健身不沉肩 斜方会大 不挺胸 下背会弯 圆肩 手背一般会朝前 高低肩 手长短不一 基础代谢接近代谢区间上限的50以内，属于高基础代谢

低代谢人群适合少吃多餐， 练力量 或者少量有氧。小重量 多次数长时间 把力量当做有氧训练，减少间歇。 起码三个月才会减体重。主要以大肌群训练为主。起码半年人会瘦，但体重会上涨 掉代谢的原因：

  1. 挨饿了
  2. 练狠了
肩胛骨上移 结构​

评估 站姿对比锁骨与肩胛冈高度， 锁骨要比肩胛冈一指。对比两侧肩胛冈高度，应在一条直线。 建议 放松拉伸肩胛提肌 训练 下斜方肌肉。动作 1.肩胛回缩 肱骨外旋，肩带下沉。2.直臂高位下拉 3.俯身类动作。 胸曲角度45°正常 直角肩 胸曲角度大会有气场

肱骨前移 结构​

评估：胸锁骨与肩之间夹角45°正常。 放松拉伸胸小肌（胸小肌紧张，会有翼状肩胛）扳机点 男：站在会员头侧，双手叠加，胸锁二分之一，向下二指，第三指按压10s松3s。 放松胸小肌筋膜：站于头侧，拽同侧手，直臂下压胸小肌，压水动作重复。 女：站在会员身体一侧，拉直同侧手，掌根按住胸小肌位置，手部先小范围画圈，再大范围画圈。 拉伸：坐于身体一侧，会员背向侧躺，肘向后，压手腕坐外旋。或者会员背向侧躺，教练按住腰，后下拉伸大臂。 坐姿: 会员手放对侧腿膝盖，抬手。教练抓手肘，对侧手推肩，会员与力量方向对抗拉伸。 训练：双手叠加放胸前，胸式呼吸
