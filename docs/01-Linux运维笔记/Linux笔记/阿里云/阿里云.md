## 第一章：服务器基础知识

### 1.1 服务器分类

服务器是提供计算服务的设备，根据形态和部署方式，主要可以分为以下几类：

| 分类              | 类型                | 备注                                                         |
| ----------------- | ------------------- | ------------------------------------------------------------ |
| **物理服务器**    | 1. **机架式服务器** | 最常见，外形像抽屉，需要放进机柜。                           |
|                   | 2. **刀片式服务器** | 节省空间，高密度，在机箱内垂直插入。                         |
|                   | 3. **塔式服务器**   | 外形类似普通台式机，无需机柜。                               |
| **云服务器**      | 1. **国内**         | 阿里云、腾讯云、华为云等。                                   |
|                   | 2. **国外**         | AWS (亚马逊云)、GCP (谷歌云)、Azure (微软云)。               |
| **私有云/虚拟化** | -                   | 使用 `ESXi`, `KVM`, `OpenStack` 等技术在自有硬件上构建云环境。 |

### 1.2 物理服务器结构详解

物理服务器主要由 CPU、内存、磁盘、RAID卡、远程控制卡、网卡、电源等核心部件组成。

#### 1.2.1 CPU 与核心

| 概念                 | 解释                                                         |
| -------------------- | ------------------------------------------------------------ |
| **核心 (Core)**      | CPU中负责处理用户请求或任务的单元，一个核心同一时间处理一个请求。 |
| **CPU数量**          | 指物理服务器上安装的CPU颗数，每颗CPU可以包含多个核心。       |
| **多核心 vs 单核心** | 多核心可以并行处理多个请求，效率更高。Intel的超线程技术可以让一个物理核心模拟成两个逻辑核心，进一步提升并发处理能力。 |

#### 1.2.2 磁盘与RAID

磁盘的性能受接口类型影响，常见接口有 `SATA`、`SAS` 和 `PCI-E` (固态硬盘)。

**RAID (独立磁盘冗余阵列)** 是一种将多块独立的硬盘组合起来，形成一个逻辑驱动器的技术，用于提升性能或提供数据冗余。

| RAID级别    | 硬盘数量 | 容量损失    | 性能                   | 冗余性               | 应用场景                             |
| ----------- | -------- | ----------- | ---------------------- | -------------------- | ------------------------------------ |
| **RAID 0**  | 至少2块  | 无          | 读写性能提升           | 无                   | 对性能要求高，但数据不重要的场景。   |
| **RAID 1**  | 至少2块  | 50%         | 读性能提升，写性能不变 | 高 (镜像)            | 对数据安全性要求高的场景，如数据库。 |
| **RAID 5**  | 至少3块  | 1块硬盘容量 | 读写性能均提升         | 有 (允许坏1块盘)     | 兼顾性能、成本和安全性。             |
| **RAID 10** | 至少4块  | 50%         | 读写性能均提升         | 高 (允许每组坏1块盘) | 对性能和安全性要求都非常高的场景。   |

```
      RAID 0 (条带化)             RAID 1 (镜像)
+----------+----------+      +----------+----------+
|  Disk 1  |  Disk 2  |      |  Disk 1  |  Disk 2  |
|  [ A1 ]  |  [ A2 ]  |      |  [  A  ]  |  [  A  ]  |
|  [ B1 ]  |  [ B2 ]  |      |  [  B  ]  |  [  B  ]  |
+----------+----------+      +----------+----------+
   数据分块，并行读写            数据完全复制

      RAID 5 (带奇偶校验)
+----------+----------+----------+
|  Disk 1  |  Disk 2  |  Disk 3  |
|  [ A1 ]  |  [ A2 ]  |  [ AP ]  |  (AP为A1,A2的校验)
|  [ B1 ]  |  [ BP ]  |  [ B2 ]  |  (BP为B1,B2的校验)
+----------+----------+----------+
   数据分块+校验信息，允许单盘故障
```

#### 1.2.3 远程控制卡

远程控制卡（如DELL的iDRAC、HP的iLO）是独立于服务器操作系统的管理工具，即使服务器关机或系统崩溃，也能通过网络进行远程管理。

**物理服务器使用流程:**

1. **配置远程控制卡**: 设置IP地址，实现远程访问。
2. **配置RAID**: 根据需求创建虚拟磁盘 (VD)。
3. **部署系统**: 使用U盘或网络方式 (Cobbler) 安装操作系统。
4. **配置应用软件**: 如LNMP环境。
5. **关机上架**: 将服务器放入机房机柜。

**配置DELL iDRAC (示例):** 开机时按 `Ctrl+E` 进入配置界面，设置IP地址、子网掩码和网关。

### 1.3 IDC机房知识

- **机柜**: 标准尺寸为19英寸宽，42U高 (1U ≈ 4.45厘米)。
- **散热与供电**: 需考虑散热和电流限制 (通常为10A)。
- **BGP (边界网关协议)**: 实现单IP多线路，为网站加速，云服务器普遍采用。
- **CDN (内容分发网络)**: 通过分布式缓存为网站加速。

## 第二章：云服务器入门

### 2.1 主流云服务商

| 地区     | 服务商                                       |
| -------- | -------------------------------------------- |
| **国内** | 阿里云、腾讯云、华为云                       |
| **国外** | AWS (亚马逊云)、GCP (谷歌云)、Azure (微软云) |

### 2.2 阿里云核心概念

| 名词                                  | 含义                                                         |
| ------------------------------------- | ------------------------------------------------------------ |
| **ECS (Elastic Compute Service)**     | 云服务器，相当于一台虚拟的物理服务器。                       |
| **SLB (Server Load Balancer)**        | 负载均衡，将流量分发到多台ECS上。                            |
| **RDS (Relational Database Service)** | 云数据库，提供稳定可靠的数据库服务。                         |
| **OSS (Object Storage Service)**      | 对象存储，用于存储图片、视频等海量非结构化数据。             |
| **NAS (Network Attached Storage)**    | 文件存储，多台ECS可共享访问。                                |
| **VPC (Virtual Private Cloud)**       | 虚拟私有云，逻辑隔离的网络环境，相当于虚拟局域网。           |
| **安全组**                            | 虚拟防火墙，控制ECS实例的出入流量（默认为白名单，即只允许明确设定的规则通行）。 |
| **EIP (Elastic IP)**                  | 弹性公网IP，可以与ECS实例动态绑定和解绑的公网IP地址。        |
| **实例**                              | 指一个云服务资源，如一台ECS服务器或一个RDS功能。             |
| **RAM (Resource Access Management)**  | 访问控制，用于创建和管理子用户（普通用户），并控制其对云资源的访问权限。 |
| **释放**                              | 删除云资源实例。                                             |

```
      |   EIP   | (弹性公网IP)

           |

      +---------+

+-------+ +-------+ +-------+

```

## 第三章：网站搭建实战

### 3.1 网站上线流程

1. **获取一台云服务器** (以阿里云ECS为例)。
2. 在服务器上**搭建网站运行环境** (如LNMP)。
3. **购买一个域名**。
4. **域名备案** (如果服务器在国内，且网站对公网开放)。
5. **配置DNS解析**，将域名指向服务器IP。

### 3.2 核心操作步骤

#### 3.2.1 创建ECS服务器

- **登录阿里云控制台**并进入ECS管理页面。
- **创建实例**：选择计费方式（按量付费适合实验）、地域、实例规格、镜像（操作系统）。
- **配置网络和安全组**：创建VPC和安全组，并开放必要的端口（如80端口用于HTTP访问）。
- **配置存储**：系统盘和数据盘。
- **设置登录密码或密钥**。

#### 3.2.2 配置DNS解析

- **进入域名控制台**，选择需要解析的域名。
- **添加记录**，配置记录类型、主机记录、解析线路和记录值。

**记录类型说明:**

| 记录类型   | 作用                                          | 示例                                |
| ---------- | --------------------------------------------- | ----------------------------------- |
| **A记录**  | 将域名指向一个IPv4地址。                      | `www.example.com` -> `1.2.3.4`      |
| **CNAME**  | 将域名指向另一个域名（别名），常用于CDN加速。 | `cdn.example.com` -> `xxx.cdn.com`  |
| **MX记录** | 用于配置企业邮箱。                            | `example.com` -> `mail.example.com` |
| **TTL**    | (Time To Live) DNS缓存记录的时间，单位为秒。  |                                     |

### 3.3 实验资源释放流程

为了避免不必要的费用，实验结束后请及时释放所有资源。

1. **释放ECS实例和弹性公网IP (EIP)**。
2. **释放VPC和安全组** (如果不再需要)。
3. **删除RAM子用户**。
4. **删除DNS解析记录**。
5. **释放自定义镜像和快照**。
