## 怎么投稿到本站

把 Markdown 文件放到对应目录后推送到 `master` 即可自动发布：

| 内容 | 目录 |
|------|------|
| 技术笔记 | `docs/linux/<主题>/` |
| 健身训练 | `docs/fitness/training/` |
| 运动康复 | `docs/fitness/rehab/` |

侧边栏会按目录自动更新，一般不用改 `sidebars.ts`。
